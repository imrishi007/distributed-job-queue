# Distributed Job Queue

A learning-first distributed job queue and task processing system built step by step.

- **Backend / workers:** C++ (modern C++, CMake)
- **Queue:** Redis
- **Persistence:** PostgreSQL
- **Dashboard:** React (Vite)
- **Packaging:** Docker + Docker Compose

## Status

- [x] Phase 0 — Foundation (environment verified, repository + toolchain)
- [ ] Phase 1 — C++ HTTP API server

Each phase is implemented and explained one step at a time; see `docs/`.
